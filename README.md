# Sistema de Autogestión para Estudiantes

Este proyecto es un Sistema de Autogestión para Estudiantes desarrollado utilizando el stack MERN (MongoDB, Express.js, React.js, Node.js). El sistema permite a los estudiantes y administradores gestionar de manera eficiente las inscripciones a materias, exámenes, ver el estado académico y realizar otras tareas administrativas.

## Características

- **Gestión de Estudiantes**: Los administradores pueden agregar, editar y eliminar estudiantes.
- **Inscripción a Materias y Exámenes**: Los estudiantes pueden inscribirse a materias y exámenes desde su cuenta.
- **Visualización de Estado Académico**: Los estudiantes pueden ver sus calificaciones, materias cursadas y exámenes pendientes.
- **Autenticación y Autorización**: Implementado con JWT para proteger las rutas y asegurar la integridad de los datos.
- **Panel de Administración**: Herramientas administrativas para gestionar carreras, materias y usuarios.

## Requisitos Previos

- Node.js (v14.x o superior)
- MongoDB (v4.x o superior)
- npm (v6.x o superior) o Yarn
